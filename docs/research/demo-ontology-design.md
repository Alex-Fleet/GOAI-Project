# Demo 深度本体设计（DMC-50H 五轴加工中心）

> 目标：一台 DMC-50H 加工中心构建 400+ 节点完整本体（每系统深挖到参数/标准/异常/症状/故障/关联）。
> 数据策略：真实数据优先（厂商规格/标准/材料牌号）→ 无真实数据用行业标准值/常识（标注来源）。

## 内容清单（构建依据）

### A. 设备总体
- 工作台尺寸 / 行程 X/Y/Z/A/C / 快速进给 / 定位精度 / 重复定位精度 / 最大承重 / 主轴锥度(BT40/HSK-A63) / 整机重量

### B. 主轴系统
- 主轴本体：最高转速 / 额定功率 / 扭矩 / 变速方式
- 主轴轴承：型号(SKF/NSK) / 布置(前3+2/后2) / 预紧力 / 精度(P4) / 润滑脂 / 温升限值 / 极限转速
- 润滑系统：脂量 / 补脂周期 / 油品牌号
- 冷却：冷却液型号(乳化液) / 浓度 / 压力 / 流量 / 温度上限 / 过滤精度
- 密封：型式 / 防尘等级

### C. 进给系统
- 伺服电机：额定扭矩 / 转速 / 功率
- 滚珠丝杠：导程 / 直径 / 精度等级(C3) / 预紧力
- 直线导轨：型号 / 滑块数 / 直线度 / 承载 / 润滑
- 编码器：分辨率 / 精度
- 反向间隙

### D. 刀库系统
- 刀库：容量 / 换刀时间 / 刀柄形式
- 刀具：面铣刀/立铣刀/钻头/镗刀/铰刀/丝锥（各：材质/直径/刃数/螺旋角/涂层/寿命）
- 刀柄：锥度 / 拉钉 / 动平衡等级

### E. 夹具系统
- 液压夹具：液压压力 / 夹持力 / 保压时间 / 泄漏
- 定位元件：定位精度 / V型块 / 定位销
- 夹紧元件：夹紧力 / 行程 / 磨损

### F. 测量系统
- 传感器：转速/负载/温度/振动/位移/力（各：量程/精度/采样率）
- 测头：对刀仪 / 工件测头

### G. 结构
- 床身：铸铁牌号 / 刚性 / 阻尼；立柱 / 滑枕 / 工作台(T型槽)

### H. 材料知识
- 工件：45#结构钢/40Cr合金钢/6061铝（屈服/抗拉/硬度/弹性模量/应力/疲劳/热处理）
- 刀具材料：硬质合金(YG6)/高速钢/涂层
- 轴承钢：GCr15（硬度/疲劳/接触应力）

### I. 标准
- ISO 10816（振动分级）/ ISO 230（精度检测）/ 合格限

### J. 工艺参数
- 每刀具切削参数：转速/进给/切深/冷却

### K. 故障因果（自洽网）
- 症状细分：空切/过载/异响(尖啸/咔哒/隆隆)/振动(高频/低频)/温升/精度下降/噪声
- 故障：轴承磨损(疲劳/润滑不足/过载/污染)/丝杠磨损(预紧失效/润滑)/导轨磨损(污染/润滑)/刀具磨损(切削参数/材质)/液压泄漏/传感器漂移/冷却不足/润滑不足
- 每故障：候选原因 / 证据判定 / 影响缺陷
- 缺陷：表面粗糙/平行度/同轴度/尺寸/形状

### L. 参数↔异常↔症状↔故障
- 每参数：标准值 → 上限/下限 → 过大/过小 → 对应症状 → 故障

### M. 业务层
- 合同/订单/客户/违约/损失（已有）
