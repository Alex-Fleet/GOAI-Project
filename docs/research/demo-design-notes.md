## 1. Demo 展示什么（对外口径）

**一句话**：质检说"气缸底表面太粗糙"，系统沿工艺链下钻，发现根因不在铣床、在"来料被锯短了"——而且是质检称重都查不出来的毛病。

**三幕**：
1. **触发**：质检报告"气缸底 111501，表面粗糙度 4.49（上限 2.5）"。常规做法：判不合格、报废、认栽。
2. **下钻**：系统沿工艺链查 DMC-50H 铣床工艺信号 → 端面铣削电流只有正常的 1/40 = **空切**，铣刀没吃到料。不是设备坏了，是"没料可铣"。
3. **追根因**：查来料 → 锯切重量 0.538 称重合格，但对比正常 0.569 轻了 4% → **来料被锯短了**。质检重量线（下限 0.495）划太宽，抓不住 4% 偏差；是铣床"空切"信号暴露了它。

**卖点（评审视角）**：
- **真推理**：不用官方标注，纯工艺信号盲推，事后对照官方标注正确
- **质检盲区穿透**：传统质检抓不住的问题，靠跨工序工艺信号发现
- **可审计**：每步证据可回放、哈希锁定
- **通用**：一楼契约零业务词，换行业换配置可用

## 2. 数据支撑（已验证的事实）

- **盲推规则**：DMC-50H 端面铣削（face_milling 子工序）主轴电流均值 + 负载均值，越出正常工艺窗口即判铣削异常。窗口取自 30 个正常样本均值±3σ：电流 [1.49, 3.39]，负载 [2.92, 5.35]。
- **全量验证**（178 样本：98 异常1 + 39 异常2 + 11 异常3 + 30 正常）：正常误报 3.3%；异常1（原料短）99% 检出；异常2（夹持）38.5%（工艺信号与正常重叠）；异常3（杂项）27.3%（官方称数据不可见）。
- **异常类型**（官方标注定义）：0 正常 / 1 锯切原料对齐不良切太短 / 2 铣削夹具夹持不平 / 3 杂项（工艺数据不可见）。
- **数据发现**：表面粗糙度 SR>3 的 99 个零件里，70 个官方标注 anomaly=1（来料短），0 个 anomaly=2。来料锯切重量 985 个全部在合格线（0.495-0.641）内，但异常1 重量均值 0.546 vs 正常 0.569，轻约 4%——**质检盲区真实存在**。
- **信号指纹**：空切（电流极低 1/40）→ 主要指向来料短；过载（电流/负载显著偏高或尖峰）→ 主要指向夹持。**信号方向能区分根因**。

## 3. 系统实际做什么（2026-08-15 实测）

**demo 已落地**（engine/demo/ + engine/scripts/download_cipdmd.py）：
```
质检触发(SR 超标) → L1 工艺图定位 → L2 盲推检出(空切/过载)
  → L2-attribution 归因(候选排除→锁定根因) → L4-root-cause 责任(跟随根因)
```
- **检测**：face_milling 电流/负载 3σ 窗口 → 空切/过载/正常。
- **归因**（demo/tbox.py + attribution.py）：空切/过载 → 候选 Fault（CAUSES 分叉）→ 逐候选查 ABox 证据（来料重量/过载/刀具）→ 排除 → 锁定。
- **责任跟随根因**（serve_demo）：来料短 → SUP-B（CL-2）；夹持 → SUP-A（CL-1）；无法归因 → FAILED 不硬出结论。
- **深度本体**（kb_build.py）：**407 节点 625 边**（14 类型）——DMC-50H 五轴机完整深挖（主轴/进给三轴/刀库/冷却/夹具/测量/结构/材料/ISO 标准/工艺参数/故障因果自洽网），孤立节点清零、横向网状关系 39 条。
- **LLM 三职责**（demo/llm_service.py）：人话表达（DeepSeek 生成溯源报告）、NLU 解析（/nlu_parse）、探索提议（图约束：候选必须 ⊆ TBox 候选集）；key 仅 env 读（DEEPSEEK_API_KEY），无 key/失败确定性兜底。
- **WEBUI**（engine/frontend/）：挂载即批量归因（98 件）→ 归因结果按钮（推理后出现）→ 点开单件链；d3-force 本体图（缩放/平移/拖节点/点节点看 ABox+TBox）；SSE 流式叙事 + Markdown 渲染；对话框问答；违约金测算 + 哈希链展示。
- **测试**：72 全绿（65 一楼 + 7 demo），ruff 干净。
