# PRD：工业质量事故追责与全局处置 Agent

> 项目：GOAI 世界人工智能开源大赛 · 无界应用 · AI+工业制造
> 文档类型：产品需求文档（Product Requirements Document）
> 关联：docs/idea_v2.md（Idea v2 概念基线）

## 1. 问题陈述

制造企业发生质量事故（如某批次产品质检不合格）时，追责与处置依赖人工跨系统翻查：MES 查工艺、QMS 查检验记录、ERP 查工单与合同，影响面靠人脑估算。结果是**慢**（事故响应以天计）、**漏**（关联批次/客户易遗漏）、**不可审计**（结论无依据链，无法满足 ISO 9001 / SEMI 强制追溯与合规取证）。

质量追溯是工业强制要求，现有系统只能"事后查记录"，不能"主动推理、全链推演"。这是真实硬痛点，不是想象。

## 2. 目标与定位

一句话定位：**"AI 提出，逻辑审判"**——一个用确定性推理做决策、白箱可审计的工业质量事故追责 Agent。一次质检不合格，5 条推理链从缺陷追到设备根因、从根因前推到客户合同与产线重排，每个结论带依据链，决策正确性来自**确定性逻辑推理**而非 LLM 概率。

- **做什么**：把"缺陷 → 工艺 → 设备 → 产品 → 客户 → 排产"的牵一发动全身，一次性推演清楚并可视化。
- **给谁**：质量工程师（追根因）、生产主管（处置排产）、合规审计（取证）。
- **解决什么**：追责慢、影响面算不清、结论不可审计。

> 定位取舍：作为 GOAI 演示作品交付，不期待真正被他人复用；但架构层面**领域知识与数据沙盘解耦、配置驱动**，演示时展示"换行业仅换数据"的可复用能力，覆盖评审"开放复用价值"维度。

## 3. 目标用户 + 典型场景

| 用户 | 使用方式 | 频次 |
|------|---------|------|
| 质量工程师 | 事故发生时上传质检报告，看追责链与根因 | 偶发但高代价 |
| 生产主管 | 看影响面与处置方案，确认后执行 | 同上 |
| 合规审计 | 回放推理链取证、核对依据 | 审计周期 |

**典型场景走一遍**（演示主故事线）：

1. 质检发现"晶圆批次 W-1024 在刻蚀工序的工艺特征超差（刻蚀速率偏移 12%，超出规格上限）"。
2. **链1**：缺陷批次 → 工艺环节追溯（质量×工艺知识域）：命中刻蚀工序、工艺窗口参数。
3. **链2**：设备根因诊断（设备知识域 + FDC 信号证据）：CHAMBER-3 机台的 RF 功率漂移，判定为根因。
4. **链3**：影响面前推（BOM×工单知识域）：W-1024 批次进入哪些晶圆盒/在制品/成品、波及多少工单。
5. **链4**：客户合同影响（合同知识域）：命中合同违约条款、报废/召回范围与损失额。
6. **链5**：处置与产线重排（排产×供应链知识域）：替代机台方案 + 产线重排建议。
7. 生产主管确认 → 系统更新沙盘、生成追责报告，全程每步白箱可回放。

## 4. 功能清单

**P0 · 核心闭环（一次事故 = 5 条推理链 + 1 个执行闭环，全部必做）**

| # | 功能 | 说明/交互方式 | 对应赛道偏好 |
|---|------|--------------|-------------|
| F1 | 多模态质检解析 (VLM/LLM) | 支持上传 **晶圆缺陷检测(WDI)图片** 或 **质检文本**，提取缺陷类型/批次 | 多模态 (加分项) |
| F2 | 链1：缺陷批次 → 工艺环节追溯 | 质量×工艺知识域：定位到刻蚀/薄膜沉积工序 | 知识增强 |
| F3 | 链2：设备根因诊断 | 设备知识域 + SECOM/FDC 信号：判定为刻蚀机台参数漂移/炉管温漂 | 设备运维协同 |
| F4 | 链3：影响面前推 (BOM×工单) | 波及晶圆盒/在制品/成品/工单穿透查询 | 供应链协同 |
| F5 | 链4：客户合同影响 | 报废/召回范围/违约损失额（对比 SEMI / ISO 9001 / 合同条款） | 业务闭环 |
| F6 | 链5：处置建议与产线重排 | 给出替代机台及重排建议 (排产×供应链知识域) | 流程编排 |
| F7 | 交互闭环：人确认 → 系统执行 | 点击 [确认执行]，SQLite 更新沙盘状态 (冻结批次/变更排产)，出具处置单 | 任务闭环 (核心) |
| F8 | 三栏工作台 UI | 推理链图谱 + 原始证据面板 (信号曲线/图片) + 影响处置看板 | 可运行 Demo |
| F9 | 白箱依据链与合规映射 | 结论附加原始数据依据 + SEMI / ISO 9001 条款映射 | 可审计性 |

**P1 · 重要**
- F10: Before/After 处置对比（处置前后影响面/损失变化可视化）
- F11: 一键生成并导出《ISO 9001 质量事故追责与处置报告 (PDF)》

**P2 · 锦上添花**
- 可复用展示：配置驱动切换行业/产品线（演示"换数据即换工厂"）
- 知识域一致性检测 / 规则动态推理演示

## 5. 不做清单

- ❌ 排产优化求解（OR-Tools/GA 求解器）——只给替代方案，不求解最优
- ❌ 收益最大化 / 定价财务模型
- ❌ 实时产线控制 / SCADA 接入
- ❌ 多 Agent 协作 / 多模型路由
- ❌ 完整 MES/ERP 复刻
- ❌ 真实合同的法律效力判断（只做条款命中与损失估算）

## 6. 成功指标（可验证）

- Demo 可在 **≤3 分钟**内走完一次事故完整闭环（7 步典型场景）。
- **5 条推理链全部点亮**，每条链 = 推理链高亮 + 原始证据 + 依据来源。
- 影响面数字（波及工单数 / 客户数 / 违约损失额）可对照沙盘数据**独立核验一致**。
- 有 **Before/After** 处置对比。
- 演示可见"换行业仅换数据"的可复用性（配置切换）。

## 7. 约束与风险

**行业选择：为什么是半导体晶圆制造**

- **开源数据最硬**：SECOM 数据集是**唯一一份真实半导体制造过程质检数据**（工艺参数 + pass/fail 标注），"质检不合格 → 触发推理"整条链路跑在真数据上，不靠人工映射硬贴。
- **场景天然成立**：晶圆批次 → 工序（刻蚀）→ 设备（机台参数漂移）→ 产品/客户 → 排产，一次质检失败即可引爆完整推理链，符合"牵一发动全身"的演示主线。
- **对照**：汽车 PCBA 路线需将 SECOM/CWRU 信号映射为贴片机/回流焊（信号形态不一致），一戳就穿；半导体路线数据、标准、流程全部对口。

| 类型 | 内容 |
|------|------|
| 场景统一 | **半导体晶圆制造（wafer fab，成熟制程）**，兼顾 SEMI 标准体系（如 SEMI E10 设备可靠性）与 ISO 9001 质量管理规范，辅以行业选择说明（见上）。 |
| 数据映射机制 | 1. **信号层**：<br> - 质检触发：SECOM 数据集原样使用（本即半导体制造工艺参数 + pass/fail 标注），作为质检不合格触发信号与根因特征；<br> - 缺陷视觉：开源晶圆缺陷检测（WDI）图片，作为缺陷类型解析输入；<br> - 设备健康：NASA/CWRU 退化信号作为刻蚀机辅助设备（真空泵/机械手）健康形态背书。<br>2. **知识层**：SEMI、ISO 9001、工厂 QC 规程转化之领域公理/规则。<br>3. **业务层**：SQLite 构建 fab 的 BOM（晶圆→die→产品）、工单、客户合同（含延期违约金条款）。 |
| 架构与推理约束 | **神经-符号架构 (Neuro-Symbolic)**：神经侧（多模态模型/LLM）仅负责把非结构化输入（质检报告/缺陷图片/工艺信号）解析为结构化事实；符号侧做确定性推理，对决策结论负责。约束：**决策结论由确定性推理产生，可审计可回放；LLM 不直接输出任何决策结论。** 具体推理技术形态（图结构遍历 / 规则引擎 / 逻辑推理）由推理需求决定——本场景以**关系图遍历为主**，架构阶段再定，本 PRD 不锁定技术选型。 |

**风险与待定**：

- **知识域规模**：6 域（质量/工艺/设备/产品BOM/合同/排产供应链）建模工作量是最大风险，优先保证 P0 五链闭环，P2 展示性推理后置。
- **LLM 幻觉**：LLM 只产出结构化触发事件与人话解释，所有决策结论由确定性推理产生，杜绝 LLM 直接出结论。
- **数据源细节**：SECOM 工艺参数与 fab 设备/工序的映射方式（FDC 信号形态背书）需在 demo 设计阶段定稿，待定。
- **指标口径**：演示时长与损失金额量级按上表执行，如需调整在 demo 验收时复核。

## 8. 验收标准

- [ ] 一次事故 7 步典型场景完整可演示，≤3 分钟。
- [ ] 5 条推理链全部点亮，每条结论可追溯到原始证据与标准条款。
- [ ] 影响面数字与沙盘数据核验一致。
- [ ] Before/After 对比可见。
- [ ] 可复用性（换行业/换数据）可现场演示。
